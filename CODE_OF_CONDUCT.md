# Code of Conduct

OxiPhysics has adopted the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1, as its Code of Conduct. It applies to all project spaces — the repository, issue tracker, pull requests, and any other community interaction.

The full text is available at:
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

In short: we are committed to a welcoming, respectful, and harassment-free experience for everyone, regardless of background or identity. Participants are expected to act professionally and considerately toward others.

## Reporting

If you experience or witness a problem covered by this Code of Conduct, please report it privately to the project maintainers via the [`cool-japan/oxiphysics`](https://github.com/cool-japan/oxiphysics) GitHub repository (for example, through the repository's private vulnerability reporting, or by contacting a maintainer directly). Maintainers are responsible for clarifying standards and will take fair, appropriate corrective action. The privacy and security of anyone reporting an incident will be respected.
